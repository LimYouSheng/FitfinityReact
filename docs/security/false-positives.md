## Scope and reassessment limits

These probes establish behavior for the reviewed source, synthetic payloads and tested Chromium/WebKit configurations. They do not prove universal non-exploitability, inspect real secrets, test a compromised deployment pin/browser, certify all file formats/codecs, or replace device/deployed acceptance. The backend header check is a format guard, not a complete malware scanner. Reassess if bootstrap pin ownership, provider data handling, media sinks, MIME handling or caption rendering changes. Do not reuse these assessments for `innerHTML`, frames, document navigation or arbitrary blob downloads without a separate review.
